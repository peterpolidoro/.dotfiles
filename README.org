#+TITLE: =~/.dotfiles=

This repo is the home of my custom system configuration which enables a
consistent computing experience across multiple machines. These days I primarily
use GNU/Linux via the [[https://guix.gnu.org][GNU Guix distribution]].

This setup is based on [[https://github.com/daviwil/dotfiles]]

I manage the various configuration files in this repo using [[https://www.gnu.org/software/stow/][GNU Stow]]. This
allows me to set up symlinks for all of my dotfiles using the commands:

#+BEGIN_SRC sh
# guix system
guix install git make stow
# debian
sudo apt install git make stow
rm ~/.profile && rm ~/.bashrc && rm ~/.bash_profile
rm ~/.config/xfce4/xfconf/xfce-perchannel-xml/xfce4-keyboard-shortcuts.xml
cd ~
git clone https://github.com:peterpolidoro/.dotfiles
cd .dotfiles
# install links
make install
#+END_SRC

* Routine Updates During Migration

For a Debian 13 LXQt desktop or laptop, see [[file:Desktop.org::*LXQt settings shared between machines][LXQt setup in Desktop.org]].
=make install-lxqt= installs the dotfiles and applies the shared panels,
Kitty integration, file preferences, and six xfwm4 workspaces. Run it before
the first graphical login or from a text console after logging out. Monitor
layouts and laptop power settings stay local; existing settings are backed up.

Use =upgrade-workstation --dry-run= to preview, then =upgrade-workstation= to
update the OS and user profiles from the current channel pins.  Root Guix is
separate manual maintenance via =upgrade-guix-root=, or include it with
=upgrade-workstation --root-guix=.  The old =upgrade-guix= command preserves its
previous OS + root + user behavior.

For a focused update, =upgrade-guix-user emacs= applies the channel pins and
rebuilds only the Emacs extra profile; =upgrade-profiles emacs= rebuilds it without
pulling.  Profile arguments are now honored.  See [[file:Systems.org::*Upgrading][Systems.org]] for pin updates,
Emacs payload releases, dry-run behavior, and the later Guix Home cutover.

For Guix/AppArmor trouble on a Debian machine, sync and run =upgrade-dotfiles=,
then =setup-guix-apparmor --dry-run= and =setup-guix-apparmor --check-build=. This preserves
local rules, adds build-user access when the daemon runs as root, and
reloads validated Guix profiles without restarting the daemon. Root Guix
updates run the same repair automatically. See [[file:Systems.org::*=.local/bin/setup-guix-apparmor=][Systems.org]]
for backups, supported hosts, and diagnostics.

* Password Management

#+BEGIN_SRC sh
guix install gnupg password-store
gpg --generate-key
gpg --list-key
gpg --export-secret-keys --armor <fingerprint> > privkey.asc
gpg --export --armor <fingerprint> > pubkey.asc
pass init <fingerprint>
pass git init
#+END_SRC
