mouse_map middle release grabbed,ungrabbed paste_selection
#+end_src

Selecting text in Kitty copies it to both the primary selection and the
system clipboard.  In graphical Emacs/vterm, click the mouse wheel to paste
the primary selection, or use ordinary =C-y= to yank from the clipboard.
Kitty's existing =Ctrl+Shift+C= / =Ctrl+Shift+V= bindings still copy/paste
explicitly.  Hold =Shift= while dragging if a terminal application captures
mouse events.  Middle-click pastes the primary selection even when an agent
or tmux captures the mouse; Kitty consumes that button instead of forwarding
it to the application.  Reload Kitty configuration with =Ctrl+Shift+F5=.

On Linux/X11, Kitty supplies the primary selection automatically; no extra
clipboard package is needed.  The =copy_on_select clipboard= setting also
copies to the separate system clipboard for =Ctrl+Shift+V= or Emacs =C-y=.
In a browser, middle-click inside an editable text field.  If middle-click
still fails in every application, run =xev -event button= and click the wheel
inside its window: the press and release should report =button 2=.

To copy from vterm, enter copy mode with =C-c C-t=, select text, then press
=RET= to copy and resume output.  Paste in Kitty with the mouse wheel or
=Ctrl+Shift+V=.  Selecting text in Kitty replaces the clipboard contents;
set =copy_on_select no= if you prefer to keep mouse selection separate.

This helper updates the live LXQt terminal integration while preserving the
rest of the generated LXQt settings files.  Keeping this as a script is less
brittle than checking a whole =globalkeyshortcuts.conf= or =panel.conf= snapshot
into Stow.

For complete LXQt setup on a new machine, use [[*LXQt settings shared between machines][the shared LXQt setup]] below.
For terminal-only setup, updating or stowing the dotfiles installs the Kitty
configuration and this helper. LXQt stores the selected terminal, panel
launcher, and keyboard shortcuts in machine-local files under =~/.config=, so
run the helper once after installing the dotfiles:

#+begin_src sh
cd ~/.dotfiles
make install
~/.local/bin/use-kitty-lxqt
#+end_src

Then log out and back in, or restart =lxqt-panel= and =pcmanfm-qt=, so the live
desktop session reloads those settings.

*.local/bin/use-kitty-lxqt:*

#+begin_src sh :tangle .local/bin/use-kitty-lxqt :shebang #!/bin/sh
set -eu

backup_once() {
    file=$1
    if [ -e "$file" ] && [ ! -e "$file.before-kitty" ]; then
        cp -a "$file" "$file.before-kitty"
    fi
}

ensure_key_value() {
    file=$1
    section=$2
    key=$3
    value=$4

    mkdir -p "$(dirname "$file")"
    case ":${prepared_files:-}:" in
        *":$file:"*) ;;
        *)
            if [ -e "$file" ]; then
                backup_once "$file"
            else
                : > "$file"
            fi
            prepared_files="${prepared_files:-}:$file"
            ;;
    esac

    awk -v section="$section" -v key="$key" -v value="$value" '
      BEGIN {
        in_section = 0
        seen_section = 0
        set_key = 0
      }
      $0 == "[" section "]" {
        if (seen_section && !set_key) {
          print key "=" value
        }
        in_section = 1
        seen_section = 1
        set_key = 0
        print
        next
      }
      /^\[/ {
        if (in_section && !set_key) {
          print key "=" value
          set_key = 1
        }
        in_section = 0
        print
        next
      }
      in_section && index($0, key "=") == 1 {
        print key "=" value
        set_key = 1
        next
      }
      { print }
      END {
        if (!seen_section) {
          print ""
          print "[" section "]"
          print key "=" value
        } else if (in_section && !set_key) {
          print key "=" value
        }
      }
    ' "$file" > "$file.tmp"
    mv "$file.tmp" "$file"
}

find_kitty_desktop() {
    for dir in \
        "$HOME/.guix-extra-profiles/desktop/desktop/share/applications" \
        "$HOME/.guix-home/profile/share/applications" \
        "$HOME/.guix-profile/share/applications" \
        /usr/share/applications
    do
        if [ -f "$dir/kitty.desktop" ]; then
            printf '%s\n' "$dir/kitty.desktop"
            return 0
        fi
    done
    printf 'kitty.desktop\n'
}

kitty_desktop=$(find_kitty_desktop)

qtxdg_file="$HOME/.config/lxqt-qtxdg.conf"
mkdir -p "$(dirname "$qtxdg_file")"
backup_once "$qtxdg_file"
printf 'TerminalEmulator=kitty.desktop\n' > "$qtxdg_file"

ensure_key_value \
    "$HOME/.config/pcmanfm-qt/lxqt/settings.conf" \
    "System" \
    "Terminal" \
    "kitty"

keys_file="$HOME/.config/lxqt/globalkeyshortcuts.conf"
if [ -e "$keys_file" ]; then
    backup_once "$keys_file"
    sed 's/^Comment=QTerminal$/Comment=Kitty/; s/^Exec=qterminal$/Exec=kitty/' \
        "$keys_file" > "$keys_file.tmp"
    mv "$keys_file.tmp" "$keys_file"
fi
ensure_key_value "$keys_file" "Control%2BAlt%2BT.1" "Comment" "Kitty"
ensure_key_value "$keys_file" "Control%2BAlt%2BT.1" "Enabled" "true"
ensure_key_value "$keys_file" "Control%2BAlt%2BT.1" "Exec" "kitty"
ensure_key_value "$keys_file" "Meta%2BReturn.42" "Comment" "Kitty"
ensure_key_value "$keys_file" "Meta%2BReturn.42" "Enabled" "true"
ensure_key_value "$keys_file" "Meta%2BReturn.42" "Exec" "kitty"

panel_file="$HOME/.config/lxqt/panel.conf"
if [ -e "$panel_file" ]; then
    backup_once "$panel_file"
    escaped_kitty_desktop=$(printf '%s\n' "$kitty_desktop" | sed 's/[\/&]/\\&/g')
    sed "s#/usr/share/applications/qterminal.desktop#$escaped_kitty_desktop#g; s#qterminal.desktop#$escaped_kitty_desktop#g" \
        "$panel_file" > "$panel_file.tmp"
    mv "$panel_file.tmp" "$panel_file"
fi

printf 'LXQt terminal settings now prefer kitty.\n'
printf 'Log out and back in, or restart lxqt-panel and pcmanfm-qt, for all changes to take effect.\n'
#+end_src

* LXQt settings shared between machines

** Audit and installation

The desktop audit on 2026-10-09 found that Stow managed Kitty, fonts,
xsettingsd, and xkeysnail configuration, but no LXQt or xfwm4 settings.
Local preferences included top and bottom panels, quick launchers, ungrouped
current-workspace tasks, a custom clock format, detailed file dialogs with
hidden files visible, Kitty shortcuts, xfwm4, and six workspaces. Most other
xfwm4 values matched its defaults. LXQt appearance inherited Debian's
Papirus / Debian / Fusion defaults; the xsettingsd file alone does not set
LXQt's Qt theme or arrange to start xsettingsd.

The presets below reproduce those portable preferences on Debian 13 with
Guix user profiles. Monitor outputs, resolution, scaling, desktop icon
positions, window sizes, recent files, and battery/lid settings remain local.
In particular, the desktop's =enableBatteryWatcher=false= and
=enableLidWatcher=false= must not become laptop defaults. The existing XFCE
=displays.xml= contains desktop monitor identities and is not imported.

Install the Debian desktop packages on a new machine:

#+begin_src sh
sudo apt install lxqt lxqt-theme-debian qt6-svg-plugins xfwm4 python3
#+end_src

Install/activate the Guix desktop profile as described in [[file:Systems.org][Systems.org]] so
Kitty is available. Firefox ESR, Chrome, LXImage, and Thunar launchers are
included only when those applications are installed. Guix and Debian desktop
file paths are resolved on the destination machine; there are no saved
=/home/peter= launcher paths.

Preview from the checkout at any time:

#+begin_src sh
./.local/bin/setup-lxqt --dry-run
#+end_src

Before first LXQt login, or after logging out of the graphical session, use
a text console (e.g. =Ctrl+Alt+F3=) to install the links and apply preferences:

#+begin_src sh
cd ~/.dotfiles
make install-lxqt
#+end_src

Then select LXQt at graphical login. This command configures the desktop;
there is no need to visit the individual settings dialogs. Run it again
from a text console after pulling changes to these presets. Ordinary
=make install= and =upgrade-dotfiles= still only refresh Stow links: they do
not overwrite settings in a running desktop. The helper refuses to apply
changes while LXQt/xfwm4/xfconf processes are running because they can
rewrite the files from memory.

The helper keeps writable local files because these applications rewrite
their settings. It merges the preferences below and xfwm4's six-workspace
setting, leaving unrelated keys in those files intact. The panel layout is
replaced with the saved two-panel layout; any existing output selection is
retained by matching each panel's top/bottom edge. New machines use LXQt's
default screen selection. Existing extra panels and custom panel plugins
are replaced. Other keyboard shortcuts are preserved, including distro
brightness/display bindings on a fresh installation; duplicate Kitty
bindings are consolidated.

Changed existing files are backed up once beside the original as
=*.before-dotfiles-lxqt=. Restore those files while logged out to undo the
setup. Later GUI edits stay local until intentionally added to these
presets; Git does not automatically capture them. Edit this Org file and
retangle for shared preference changes. The merge/backup implementation is
maintained directly in =.local/libexec/lxqt-settings.py=.

** File dialogs and file manager

Only preferences are saved here; dialog geometry, navigation history, and
per-monitor wallpaper/desktop settings are intentionally absent.
The common wallpaper uses Debian's installed theme, just as on the source
desktop. Set it explicitly: a partial user file created before first login
can leave PCManFM-Qt with an empty wallpaper instead of the distro default.
The =lxqt-theme-debian= package supplies the wallpaper link and depends on
=desktop-base= for the image; =qt6-svg-plugins= supplies Qt's SVG reader.

#+begin_src sh
